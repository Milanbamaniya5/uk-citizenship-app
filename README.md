# Life in the UK Practice

Free practice tests and study guides for the Life in the UK test.

## Structure
- `src/App.jsx` - practice test app (React + Vite)
- `src/questions.js` - question sets (add more sets here)
- `public/` - static pages copied as-is to the live site: `ads.txt`, `robots.txt`, `sitemap.xml`, `about.html`, `privacy-policy.html`, `terms.html`, `contact.html`, `guides/`

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```
